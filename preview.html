OneKana Agency Website

Site web moderne et professionnel inspiré du design de vokode.com

🎨 Design Moderne

Interface élégante avec animations fluides et transitions sophistiquées inspirées du design de vokode.com.

📱 Responsive Design

Compatible avec tous les appareils : mobile, tablette et desktop. Expérience utilisateur optimale sur tous les écrans.

🚀 Performances

Technologies modernes (Vite + React) pour un chargement rapide et une navigation fluide.

✨ Animations

Animations Framer Motion pour des transitions élégantes et une expérience immersive.

🔧 Fonctionnel

Formulaire de contact, système de filtres pour le portfolio, navigation sticky et menu mobile.

🎨 Design System

Couleurs, typographie et composants cohérents pour une identité visuelle forte.

Technologies Utilisées

React 19 Vite Framer Motion CSS3 Grid & Flexbox Animations

Installation

1. Clonez le projet : git clone [repository-url]
2. Installez les dépendances : npm install
3. Lancez le serveur : npm run dev
4. Ouvrez http://localhost:5173 dans votre navigateur
Remarque : Ce site a été créé avec React et Vite. Pour le faire fonctionner correctement, assurez-vous d'avoir Node.js installé et exécutez les commandes d'installation ci-dessus.
